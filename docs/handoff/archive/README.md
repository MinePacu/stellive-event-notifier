# Handoff Archive

Every file in this directory is a historical record, not an active instruction.

Do not read archive files during normal feature work, merge-only work, routine debugging, or routine PR review. Finding an archive path in search results is not permission to open it.

Read a specific archive file only when:

- the user explicitly asks for historical context;
- a regression investigation requires old implementation history;
- a current handoff document links to that exact archived file; or
- a merge conflict directly touches archived handoff files.

Start from `docs/AI_HANDOFF.md` and prefer the smallest relevant current document.
