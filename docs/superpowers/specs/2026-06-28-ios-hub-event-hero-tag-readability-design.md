# iOS 행사 상세 히어로 태그 가독성 개선

## 목표

iPhone 행사 상세 화면의 히어로 이미지 위 태그가 밝거나 복잡한 이미지에서도 즉시 읽히도록 한다.

## 디자인

- 변경 범위는 `HubEventHeroTagView`의 시각 스타일로 제한한다.
- 상태, 행사 분류, 참여 방식의 기존 색상 구분은 유지한다.
- 태그 배경은 현재 18%보다 충분히 불투명하게 조정한다. 목표값은 78%다.
- 동일 계열색의 얇은 테두리와 약한 그림자를 추가해 이미지와 태그 경계를 분리한다.
- 크기, 글꼴, 태그 문구, 순서, 행사 데이터 및 화면 구조는 변경하지 않는다.
- 이미지 전체 그라데이션은 조정하지 않아 제목과 이미지의 기존 인상을 유지한다.

## 검증

- 스타일 정책에 자동화 가능한 값이 있다면 테스트를 먼저 추가해 실패를 확인한다.
- iOS 앱을 빌드해 컴파일 오류가 없는지 확인한다.
- 행사 상세 화면을 시뮬레이터에서 열어 밝은 이미지 위 태그의 가독성, 색상 구분, 잘림 여부를 확인한다.
- 프로젝트의 자산·플랫폼·카탈로그 정책에는 영향을 주지 않는지 변경 diff를 점검한다.
