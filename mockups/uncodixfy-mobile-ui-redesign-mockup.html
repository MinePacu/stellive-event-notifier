Stellive Hub mobile UI proposal
Serena review: Android MainActivity, iOS Home/Live/Songs/HubEvents views
현재 코드에서 확인한 구조
  • Android는 Home, Live, Songs, Goods/Events 렌더링이 MainActivity에 집중되어 있습니다.
  • iOS는 SwiftUI List와 Section 구조를 사용하며 Songs/Goods 화면에 큰 header metric card가 남아 있습니다.
  • 상단 필터 스트립과 하단 4탭 구조는 유지할 가치가 있습니다.
개선 목업 원칙
  • 장식성 상단 블록, 배경 효과, 둥근 버튼 과다 사용을 제거했습니다.
  • 필요한 상태와 메타데이터는 카드당 1줄로 제한했습니다.
  • 로고, 프로필 이미지, 팬아트, 복제 이미지 없이 placeholder만 사용했습니다.
